# Privacy

BodyTape needs no login or external service. The app's static code loads from the web host (for example GitHub Pages), but the measurements you enter are kept in local device browser storage. It makes no requests to a measurement-sync server and contains no third-party analytics or tracker script.

The app has no account system and no cross-device synchronization. CSV and JSON exports contain sensitive measurements; treat them as private files. If you choose to store backups in iCloud Drive or another service, that service's privacy terms apply.

Clearing website data or removing the installed Home Screen app may delete locally stored records. Always make your own JSON backups. Never upload private backups to a public repository.
